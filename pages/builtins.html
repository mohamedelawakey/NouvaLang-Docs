Built-in Functions

Learn how to use standard library functions provided natively by the Nouva runtime environment.

The print(...) Function

print is a globally available, variadic native function that outputs representations of any expression to standard console output (stdout).

1. Single Argument Output

print("Hello, World!");
print(42);
print(3.14159);
print(true);

2. Variadic Multiple Arguments

Pass multiple comma-separated arguments of differing types, and print will format and separate them with a space automatically:

let username: str = "Alice";
let score: int = 95;
let passed: bool = true;

print("Player:", username, "| Score:", score, "| Passed:", passed);
// Output: Player: Alice | Score: 95 | Passed: true
