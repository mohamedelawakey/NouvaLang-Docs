Installation & Setup

Download and run standalone, pre-compiled NouvaLang binaries with zero dependencies or external runtimes required.

Zero Prerequisites Required

You do not need to install Rust, C compilers, or any external packages. NouvaLang binaries are completely standalone and ready to execute out of the box!

Download Standalone Binaries

Download the official pre-compiled package for your operating system from GitHub Releases:

Operating System Architecture Archive Package Direct Download
Linux x86_64 nouva-linux-x86_64.tar.gz Download Latest
Windows x86_64 nouva-windows-x86_64.zip Download Latest
macOS x86_64 nouva-macos-x86_64.tar.gz Download Latest

Linux & macOS Quick Setup

1. Extract the downloaded archive:

tar -xzvf nouva-linux-x86_64.tar.gz

2. Give execution permission to the binary:

chmod +x nouva

3. Run the interactive shell or verify version:

./nouva --version

4. (Optional) Make nouva available globally across your system:

sudo mv nouva /usr/local/bin/

Windows Quick Setup

  1. Download and extract nouva-windows-x86_64.zip.
  2. Open PowerShell or Command Prompt inside the extracted folder.
  3. Run the executable directly:
.\nouva.exe

Building From Source (Optional - For Contributors)

If you are contributing to the compiler or want to compile from source, you can build with Cargo:

# Clone repo
git clone https://github.com/mohamedelawakey/NouvaLang.git
cd NouvaLang

# Build binary
cargo build --release

# Output path
./target/release/nouva
