# Contributing to NouvaLang Documentation

First off, thank you for considering contributing to the NouvaLang documentation! 🎉 It's people like you that make open-source documentation accurate, approachable, and great for everyone.

---

## 🛠️ How Can I Contribute?

### 1. Reporting Issues / Typo Fixes
If you find a broken link, grammatical issue, code error, or unclear explanation in the documentation, please open an issue on GitHub or submit a quick fix PR. Include:
- The page and section where the issue occurs.
- A description of what is incorrect or could be improved.

### 2. Adding Examples & Improving Explanations
Have a clearer example or want to improve a tutorial? We welcome enhancements that make complex compiler or language concepts intuitive to understand.

### 3. Submitting Pull Requests
To contribute documentation changes, follow this standard workflow:

1. **Fork the Repository:** Create your own fork of `NouvaLang_docs` on GitHub.
2. **Clone it locally:** `git clone https://github.com/your-username/NouvaLang-Docs.git`
3. **Create a Branch:** `git checkout -b docs/improve-page-name`
4. **Make your changes:** Edit the relevant HTML/CSS/JS files inside the `docs/` folder.
5. **Test locally:** Open `docs/index.html` in your browser to verify layout, links, and syntax rendering.
6. **Commit your changes:** Write a clear, descriptive commit message.
7. **Push to the branch:** `git push origin docs/improve-page-name`
8. **Open a Pull Request (PR):** Submit the PR against the `main` branch of this repository.
