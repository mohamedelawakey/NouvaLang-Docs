## 📖 Curriculum & Documentation Structure

The documentation website is organized into structured, easy-to-follow learning modules:

### 1. Getting Started
- **[Introduction & Architecture](https://mohamedelawakey.github.io/NouvaLang-Docs/):** Core design principles, lexical pipeline, and language highlights.
- **[Installation & Setup](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/installation.html):** Zero-prerequisite standalone binary downloads (Linux, Windows, macOS).
- **[CLI & REPL Usage](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/cli-and-repl.html):** Interactive shell execution and `.nv` script file runner.

### 2. Language Basics
- **[First Program: Printing (`print`)](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/first-program-print.html):** Variadic printing, console formatting, and string concatenation.
- **[Variables & Data Types](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/variables-and-types.html):** Primitive types (`int`, `float`, `str`, `bool`), mutable `let`, immutable `const`, and type inference with `auto`.
- **[Operators & Expressions](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/operators-and-expressions.html):** Comprehensive reference tables for Arithmetic, Comparison, Logical, and Compound Assignment operators.
- **[Type Casting (`as`)](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/type-casting.html):** Safe runtime conversion between primitive data types.
- **[Comments & Syntax](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/syntax-and-comments.html):** Semicolon rules, escape characters, and single/multi-line comments.

### 3. Control Flow
- **[If / Else Conditionals](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/conditionals.html):** Parentheses-free branching logic.
- **[While Loops](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/while-loops.html):** Dynamic iteration with condition checks.
- **[For Loops & Ranges](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/for-loops.html):** Numerical range traversal with auto step direction.
- **[Break & Continue](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/break-and-continue.html):** Early loop exit and iteration skipping.

### 4. Functions & Execution
- **[Function Declarations](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/functions.html):** Typed signatures with mandatory return arrows (`->`).
- **[Closures & Scopes](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/closures-and-scopes.html):** Lexical block scoping and environment isolation.
- **[Recursion](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/recursion.html):** Recursive algorithms, call stack propagation (Fibonacci, Factorial).
- **[Built-in Standard Library](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/builtins.html):** Standard runtime functions.

### 5. Practical Benchmarks
- **[Demo Programs](https://mohamedelawakey.github.io/NouvaLang-Docs/pages/demo-programs.html):** End-to-end multi-algorithm demonstration script.

## 🛠️ Architecture of the Docs Website

- **Zero Frameworks:** Pure Vanilla HTML5, CSS3, and JavaScript.
- **Zero Heavy Dependencies:** Native regex-based syntax highlighter built from scratch (no external CDN required).
- **Dark / Light Theme:** Custom theme switcher with persistent local storage.
- **Responsive Layout:** Mobile drawer and desktop sidebar toggle.
